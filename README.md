# KAUST-RNA-Seq-Analysis-of-Chromosome-17-in-a-TDP-43-Knockout-Model
Conducted within a KAUST research framework, this project explores RNA-Seq analysis of Chromosome 17 in a TDP-43 knockout model. The study includes transcriptomic preprocessing, differential gene expression analysis, and bioinformatics-driven visualization to investigate the molecular impact of TDP-43 depletion.
