# KAUST-RNA-Seq-Analysis-of-Chromosome-17-in-a-TDP-43-Knockout-Model
This project investigates transcriptomic changes on chromosome 17 in a TDP-43 knockout model using RNA-seq data from wild-type and knockout samples. The workflow includes quality control, Salmon-based quantification, gene-level aggregation with tximport, differential-expression analysis with DESeq2, and functional enrichment analysis.

Results identified 31 significantly differentially expressed genes, primarily upregulated in the knockout condition. PCA, clustering, correlation, and expression plots support clear and reproducible separation between knockout and wild-type samples. Enrichment findings highlight cytoskeletal, structural, and stress-related processes relevant to ALS and frontotemporal dementia research.
